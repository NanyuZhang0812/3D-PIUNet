# Project Instructions

## Python environment

- Always use the Conda environment named `piunet` for this repository.
- Do not use the system Python, the Conda `base` environment, or Codex's bundled/default Python runtime for project commands.
- Run Python commands as `conda run -n piunet python ...` and module commands as `conda run -n piunet python -m ...`.
- Run tests, training, evaluation, notebooks, dependency checks, and project scripts within `piunet`.
- If a package must be installed, target `piunet` explicitly, for example: `conda run -n piunet python -m pip install ...`.
- The expected interpreter is `D:\App\miniconda\envs\piunet\python.exe`.
